# GW2 Logs Parser Preconfig

Generate `.tid` files in 1 click, to upload them to a hosted [custom Gw2 TiddlyWiki](https://tiddlywiki.com/).

## Overview

Script:

1. First, convert `.zevtc` files generated by ArcDps into `.json`, using [GW2-Elite-Insights-Parser](https://github.com/baaron4/GW2-Elite-Insights-Parser)
2. Then, generate `.tid` files containing multiple Log Summaries, using [arcdps_top_stats_parser](https://github.com/Drevarr/arcdps_top_stats_parser)
3. After opening `TW5_Top_Stat_Parse.html` in a web browser (example in `\script\assets`, based on [official TW5_Top_Stat_Parse.html](https://github.com/Drevarr/arcdps_top_stats_parser/blob/main/example_output/TW5_Top_Stat_Parse.html)), import the `.tid` by drag & droping on the page to generate the final `.html` file after saving

Logs Persistance:

- (optional) Add [TW Receiver](https://github.com/sendwheel/tw-receiver) to persist all logs in a hosted `TW5_Top_Stat_Parse.html`.

# Script Usage

## System Requirements

- Python3 (https://www.python.org/downloads/)
- ~~Git (https://git-scm.com/downloads)~~ not anymore

## How to use it

In `script\` folder:

1. Install the requiered software (see. [System Requirements](https://github.com/MiryksV/gw2-logs-parser-pre-config?tab=readme-ov-file#system-requirements))
2. Open `edit_me.conf` file and specify:
   - `ARC_DPS_LOGS_DIR`: path of you ArcDps Logs directory containing the `.zevtc` files
   - `EXTRACT_DATE`: date (in `YYYYMMDD` format) to select files of a given date or of the current day (`EXTRACT_DATE=""`)
3. Excecute `Generate_stats_files.exe` \
   or \
   Excecute `Generate_stats_files.ps1` with Windows PowerShell \
   (right-click > Excecute with powerShell, or navigate to the folder and run `.\Generate_HTML.ps1`)
4. Under `\assets`, open `TW5_Top_Stat_Parse.html` in your browser of choice
5. Drag & drop all resulting `.tid` files located in the `\data\tid` folder onto the page (see step #7 of the [TW5 Top Stats Generation Steps](https://github.com/Drevarr/arcdps_top_stats_parser?tab=readme-ov-file#tw5-top-stats-generation-steps))
6. Follow steps #8 and beyond of the [TW5 Top Stats Generation Steps](https://github.com/Drevarr/arcdps_top_stats_parser?tab=readme-ov-file#tw5-top-stats-generation-steps) to generate the Log Summaries `.html` file.

# Logs Persistance

Based on [TW Receiver Setup](https://github.com/sendwheel/tw-receiver?tab=readme-ov-file#setup), to persist your logs:

1. Host the `TW5_Top_Stat_Parse.html` (or `index.html`) TiddlyWiki file on your server
2. Install the `tw-receiver` plugin by importing the `plugin_sendwheel_tw-receiver.json` into your wiki
   Save & refresh your wiki
3. Enable the plugin in Control Panel > Saving > TW Receiver
   Enable and set a strong Secret Key (password)
4. Place the `tw-receiver-server.php` file in the same directory as your `index.html`
   Set `$userpassword` on line 20 to the same Secret Key

Please find a full ready-to-use example in `script\assets\MIMs`.
